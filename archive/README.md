## 🔍 Retention Policy

### Archive Schedule
- **Daily:** Build logs, test outputs
- **Weekly:** Error reports (once resolved)
- **Monthly:** Phase summaries, feature documentation
- **Quarterly:** Technical debt audits (superseded)

### Permanent Archive
The following are kept permanently for historical reference:
- Phase implementation summaries
- Feature completion records
- Major milestone build logs
- Technical debt remediation records

Files older than 1 year may be compressed or moved to cold storage.

## 📞 Usage Guidelines

### When to Archive
1. ✅ Build/test logs older than 1 week
2. ✅ Error reports after resolution verified
3. ✅ Phase/feature summaries after completion
4. ✅ Technical debt docs when superseded
5. ✅ Any file marked "FINAL", "COMPLETE", or with old dates

### When NOT to Archive
1. ❌ Current/active documentation
2. ❌ Unresolved error reports
3. ❌ In-progress feature documentation
4. ❌ README, AGENTS.md, CLAUDE.md
