
# SaveState — Typography Addendum (v1)

Approved font stack:
- Brand / Headline: Space Grotesk
- UI / App: Inter
- Display / Accent: Orbitron (restricted use)
- Mono / Dev: JetBrains Mono

Fonts are treated as pipeline inputs.
Fonts must remain live; outlining occurs only during build steps where required.

This addendum extends the Master Brand Handoff v1.
