# 📝 Documentation Maintenance Guide

## When to Update Documents

| Situation | Document | Action |
|:----------|:---------|:-------|
| New rule established | ENGINEERING_RULES.md | Add rule + severity |
| Architectural decision made | LESSONS_LEARNED.md | Add "Decision History" section |
| New feature phase planned | ADVANCED_GAMING_FEATURES_IMPLEMENTATION_PLAN.md | Add phase + effort |
| Code pattern changes | AI_MASTER_CONTEXT.md | Update examples + references |
| Documentation issue found | AI_PROJECT_INDEX.md | Update index/navigation |

## Approval Process
1. 📝 Update document(s)
2. 🔍 Link to related documents
3. ✅ Get 1 review (architect or lead)
4. 📤 Merge to main branch
5. 📢 Notify team (optional)

## Quarterly Review
- [ ] Check all document links
- [ ] Verify metrics and numbers
- [ ] Update last-reviewed dates
- [ ] Archive outdated information
