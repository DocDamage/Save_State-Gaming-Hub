## 🎯 Known Limitations

### External Dependencies

The following features require external API configuration:

1. **Discord Rich Presence** - Requires Discord Application ID
2. **Steam Integration** - Requires Steam API Key
3. **Cloud Gaming** - Requires provider accounts
4. **Voice Recognition** - Requires speech service
5. **Hardware Monitoring** - Requires LibreHardwareMonitor

**Documentation**: See [`docs/planning/V2_FEATURE_ROADMAP.md`](docs/planning/V2_FEATURE_ROADMAP.md) for setup instructions.
