# Audio Assets

This directory should contain the UI sound effects.
The implementation expects the following files:

- `tick.mp3` (or `.wav`): For hover/selection effects.
- `success.mp3` (or `.wav`): For confirmation/success actions.

## Recommended Open Source Sources

- **Digital Tick**: [rse/soundfx](https://github.com/rse/soundfx)
- **Confirmation**: [akx/Notifications](https://github.com/akx/Notifications)
